# Runbooks

Operational playbooks. Add one per recurring incident or process.

## Suggested initial set

- `incident-realtime-pipeline-degraded.md` — diagnosis tree for >2 s sustained transcript lag.
- `incident-stt-provider-outage.md` — fallback switching procedure.
- `incident-tenant-isolation-suspected-leak.md` — sev-0 response.
- `process-knowledge-publish-rollback.md` — rolling back a bad script publish.
- `process-retention-enforcement.md` — manual run + audit of retention jobs.
- `process-deploy.md` — deploy steps + smoke checks.
