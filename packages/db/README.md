# db

Shared Prisma client + schema + migrations. Consumed by every service that touches Postgres.

## Layout

```
prisma/
  schema.prisma           single source of truth
  migrations/             generated by `prisma migrate dev`
src/
  index.ts                exported `prisma` singleton
```

## Usage

```ts
import { prisma } from '@athena/db';
const ws = await prisma.workspace.findUniqueOrThrow({ where: { id } });
```

## Migrations

Dev:
```bash
pnpm --filter @athena/db prisma:migrate:dev --name <change_name>
```

Prod:
```bash
pnpm --filter @athena/db prisma:migrate:deploy
```

## pgvector

Vector columns are added via raw SQL migrations because Prisma's vector support is incomplete. See `packages/db/prisma/migrations/<ts>_add_chunk_embedding/migration.sql` (created when knowledge ingestion lands).

## Tenant isolation

Every domain table has `workspaceId`. A future `tenant-scope` Prisma client extension will enforce this at the data layer (PRD F10).
